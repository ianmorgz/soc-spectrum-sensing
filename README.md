# soc-spectrum-sensing
The repository containing all the design and implemntation behind the SoC Spectrum Sensing project

---

## Set up
1. Download the data ```.bin``` files from the OneDrive
2. Create the virtual environment with ```python -m venv .venv``` 
3. Activate the virtual environment with ```source .venv/bin/activate```
4. Install the requirements with ```pip install -r requirements.txt```
